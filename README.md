# SparkPrompt

**SparkPrompt** is an experimental educational tool for generating prompt-writing exercises,
receiving AI-assisted feedback, and producing a refined draft. Users can bring their own Google
Gemini, OpenAI, or Anthropic API key and choose a model available to their account.

The Templates page provides concrete, provider-independent scaffolds for general AI tasks, data
analysis, web features, and machine-learning experiments.

Live Demo: <a href="https://sparkprompt.streamlit.app/">SparkPrompt</a>

## 🌟 Features

- **📝 Problem Statement Generation**: Automatically crafts concise and relevant problem statements based on your selected domain and skills.
- **🔍 Prompt Evaluation**: Delivers detailed feedback on user-generated prompts, evaluating their relevance, clarity, and completeness.
- **✍️ Prompt Refinement**: Suggests improvements to enhance the quality and effectiveness of your prompts.
- **🖥️ Interactive Interface**: Provides a user-friendly web interface for real-time interaction and feedback.

## 🚀 Getting Started

Follow these steps to set up and use Spark Prompt:

### 🛠️ Prerequisites

- Python 3.11, 3.12, or 3.13
- [uv](https://docs.astral.sh/uv/)
- A Gemini, OpenAI, or Anthropic API key

### 📥 Installation

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/Sparkience-AI/SparkPrompt.git
   ```

2. **Navigate to the Project Directory**:

   ```bash
   cd SparkPrompt
   ```

3. **Install the locked dependencies**:

   ```bash
   uv sync --locked
   ```

   The committed `uv.lock` is the reproducible dependency source for local development.

### ▶️ Usage

1. **Run the Application**:

   ```bash
   uv run --locked streamlit run app.py
   ```

2. **Access the Tool**: Open your web browser and go to [http://localhost:8501](http://localhost:8501) to start using Spark Prompt.

The Python wheel contains the reusable `sparkprompt` service, provider, prompt, and template
modules. The Streamlit UI (`app.py`, `pages/`, and `style.css`) is intentionally run from a source
checkout and is not a standalone installed application.

### 📋 How It Works

- **Generate Problem Statements**: Enter the domain and skills to generate a problem statement tailored to your requirements.
- **Evaluate Prompts**: Submit prompts to receive feedback on their effectiveness and relevance.
- **Refine Prompts**: Get suggestions to improve your prompts based on the generated problem statement.

## 🎯 Significance

SparkPrompt is intended for practice and formative feedback. Scores and suggestions are generated by
an AI model and can be inconsistent or incorrect; they are not an objective certification.

## 🔐 BYOK and privacy

Choose Google Gemini, OpenAI, or Anthropic Claude in the app, confirm the model ID, enter the
matching API key, and explicitly confirm transmission. The application creates a provider client for the current Streamlit session and
does not copy keys into the process environment or enable OpenAI response storage. Prompts and
feedback are sent only to the selected provider. Do not submit secrets or sensitive data. See
[BYOK and privacy notes](docs/privacy.md) for the current data-handling contract.

## 🤖 Agent skill

The repository includes an agent-ready SparkPrompt skill at `.agents/skills/sparkprompt`. Agents that
support `SKILL.md` bundles can install or load that folder to evaluate prompts, refine them against
a stated objective, or create prompt-writing exercises. The skill uses the host agent's model and
does not require any provider API key or call the Streamlit application.

Its evaluation suite covers correct routing, missing context, embedded instruction attacks,
sensitive data, alternative comparison, provider-key requests, and destructive-action boundaries.

Release gates are documented in the [threat model](docs/threat-model.md),
[performance envelope](docs/performance.md), [accessibility audit](docs/accessibility.md), and
[release checklist](RELEASE_CHECKLIST.md). Releases remain source/wheel based; the project does not
produce Windows installers or store packages.
